🎯 Admin Account Management - Quick Start Guide

⚡ Quick Access

📋 Features Overview

  • View all customer and job seeker accounts
  • Create new accounts with role assignment
  • Edit existing account details
  • Delete accounts with confirmation
  • Filter accounts by role (All / Customers / Job Seekers)
  • View account statistics in real-time
  • Export all accounts to CSV
  • Toast notifications for all actions

🚀 Getting Started (5 Minutes)

Step 1: Login as Admin

Use the default admin credentials:

Email: admin@hcs.com
Password: Admin123

Step 2: Navigate to Account Management

In the admin dashboard:

  • Look for "Manage Users" in the left sidebar under Administration section
  • Click it to open the Account Management Panel

Step 3: View All Accounts

The Account Management Panel displays:

  • Statistics cards (Total, Customers, Job Seekers)
  • Filter buttons for viewing specific account types
  • Table with all accounts and their details

Step 4: Create a New Account

Click "+ Add Account" to open the create form:

  • Enter First and Last names
  • Provide a unique email address
  • Set a password (6+ characters)
  • Add phone number and zip code (optional)
  • Select account type (Customer or Job Seeker)
  • Click "Create Account"

Step 5: Edit an Account

In the accounts table:

  • Click the ✏️ edit icon in the Actions column
  • Update the desired fields
  • Note: Email cannot be changed
  • Click "Save Changes"

Step 6: Delete an Account

In the accounts table:

  • Click the 🗑️ delete icon in the Actions column
  • Confirm the deletion in the popup
  • Account is permanently removed

Step 7: Export Accounts

Click "📊 Export" button to:

  • Download all accounts as a CSV file
  • File name: hcs_users_[timestamp].csv
  • Contains: Name, Email, Role, Phone, Created Date

⚠️ Important Notes

Data Storage: All accounts are stored in browser LocalStorage. Clearing browser data will delete all accounts. For production, integrate with a database backend.
Security: Passwords are currently stored in plain text. For production, implement password hashing and secure authentication.
Email Uniqueness: The system prevents duplicate emails. You cannot create two accounts with the same email address.

🔧 Keyboard Shortcuts

  • Tab - Navigate between form fields
  • Enter - Submit form (in input fields)
  • Escape - Close modal/panel (click ✕ button)

🆘 Troubleshooting

❓ Account won't save

  • ✓ Check email field is unique
  • ✓ Verify all required fields are filled (marked with *)
  • ✓ Check browser console for error messages

❓ Can't see accounts in table

  • ✓ Make sure you're logged in as admin
  • ✓ Check the filter buttons - you might be filtering out all accounts
  • ✓ Try refreshing the page

❓ Export doesn't download

  • ✓ Check browser popup blocker settings
  • ✓ Check Downloads folder
  • ✓ Try again with fewer accounts
